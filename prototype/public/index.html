      01 · Target agents

      选择发现端

      共享来源固定写入 ~/.agents/skills；目标 Agent 只能从已识别白名单中选择。

      02 · Safety boundary

      写入规则

      • 本地 Skill：共享目录和 Agent 目录使用受管符号链接。
      • 外部 Skill：仅允许工作流中已接受的 find-skills 候选。
      • 外部来源先安装再扫描；高风险会立即断链并移入隔离区。
      • 不运行 Skill，不使用 sudo，不自动重试网络失败。

      03 · Reproducible intent

      项目 Skill Kit

      把已保存的选择导出为不含路径和命令的项目意图清单；导入只核对本机状态，不自动同步或删除。

      导入文件不会创建候选、安装计划或文件写入。
