# Capability Atlas 0.6 验收记录

验收日期：2026-08-04（Asia/Shanghai）
环境：macOS、Node.js 26.3.1、`@modelcontextprotocol/sdk` 1.30.0、Codex 应用内浏览器

## 结论

0.6 保留“工作流选择 → Skill 证据确认 → MCP 安装提案 → Web 人工确认 → 受控安装/扫描/复评”的闭环，并新增“结构化需求 → Project Brief 访谈/冻结 → 九阶段 Playbook → 模板迁移/差异审阅/不可变确认 → 人工执行与质量门 → 样例/初级开发者验证 → 同源 Markdown/PDF”的闭环。

可信 MCP 连接会自动确保回环地址 Web 后台就绪：先健康探测并复用已有实例，端口空闲时才以独立子进程启动 `server.mjs`，外部应用占用端口时不接管。自动启动服务不等于授权安装；MCP 仍然只能创建和读取安装提案，只有用户在 Web 页面中确认后，服务端才会写入受管 Skill 路径。

## 隔离浏览器验收

### 开发手册

使用隔离数据目录在 `390 × 844` 移动视口和桌面视口完成真实流程：冻结完整 Brief、生成 9 阶段/18 步手册、迁移缺少模板指纹的旧版本、审阅 38 项差异并确认 v2、完成 18/18 步骤和 9/9 质量门，再按序保存 sample-run 与 novice-validated QA 证据。页面显示最高等级、当前哈希和两条记录，模板迁移警告消失；旧 v1 进度保留为 stale。桌面和移动端均无横向溢出，PDF 按钮实际下载 `development-playbook.pdf`，控制台 0 错误/警告。

### Skill 安装

浏览器使用独立 `CAPABILITY_ATLAS_HOME_DIR` 和数据目录，未写入用户真实 Agent 目录。完整流程如下：

1. 页面加载已保存工作流，选择 Codex，生成“Skill 安装回执单”。
2. 计划只包含一项已人工确认的本地 fixture，并展示来源、共享路径、目标路径和冲突状态。
3. 保存选择并二次确认执行；服务在隔离 HOME 中建立共享链接和 Codex 链接。
4. 首轮验证发现 `/tmp` 与 `/private/tmp` 路径别名会生成悬空相对链接；修复为先解析父目录再计算相对链接，并增加回归测试。
5. 第二轮验证发现 `supportedAgents: ["*"]` 会在归一化后丢失通配语义；修复为归一化前识别通配符，并增加回归测试。
6. 最终回执状态为 `completed`，项目状态为 `installed`，安全扫描 `passed / none`，重新扫描同时从 `agent-skills` 与 `codex` 发现该内容。
7. Codex 重新评估结果为匹配 `80.8%`、覆盖 `100%`、必需能力缺失 `0`，并提示重新加载 Agent。
8. 两个链接均为符号链接，且 `realpath` 指向同一来源；安装器空闲，`needsRepair=false`。

浏览器控制台没有产品运行错误；记录中的轮询警告来自验收过程中两次主动重启本机服务。

## 信任与安全边界

- MCP 与 Web 共享本机原子 JSON 存储；连接 MCP 只自动启动可视化后台，执行仍要求 Web 人工确认，不会自动获得写权限或安装 Skill。
- 外部安装仅接受解析后的包标识和固定 Agent 参数，使用 `execFile`，限制超时与输出大小。
- 本地候选执行前重新计算内容哈希；发生变化即拒绝旧计划。
- 外部 Skill 无法安装前扫描，因此 Web 必须逐项确认短暂可见风险；安装后立即扫描并按严重度处理。
- 所有自动写入仅限共享目录、白名单 Agent 目录以及应用自己的日志、快照和隔离目录。
- Skill 安装后不会运行其脚本或正文指令；运行验证仍是独立、未自动化的证据轴。

## 已知边界

1. 匹配仍是确定性、可解释的文本检索启发式，不是成功概率或真实运行评测。
2. 外部安装依赖 Skills CLI 和网络；网络失败会保留回执，但不会自动重试。
3. 安全扫描是有界静态规则，不替代沙箱、签名、供应链信誉或人工代码审查。
4. Agent 是否需要重启或重新加载取决于各 Agent 自身能力，当前只记录待加载状态。
5. 网页使用短轮询同步多进程变化，不是实时协同编辑器。
6. 样例跑通和初级开发者验证已有独立、按序、内容哈希绑定的证据记录，但 Web human actor 不是密码学身份；QA 模拟也不能替代真实外部新手研究。
7. 当前只记录人工执行、验收和证据，不自动运行项目命令、Skill 或测试。
8. Web 领域使用金标九阶段模板；其他领域仍是通用回退，需要领域专家复核。
